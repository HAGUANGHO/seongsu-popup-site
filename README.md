# 성수 팝업 지도

성수동에서 지금 열린 팝업스토어·전시·행사를 지도로 보고, 고른 곳을 걷기 좋은 순서로 이어 보는 개인 사이트예요.
매일 아침 6시에 다시 모아요.

사이트: https://haguangho.github.io/seongsu-popup-site/

## 자료 출처

- 서울시 문화행사 정보 (서울 열린데이터광장, 공공누리 제1유형)
- 브랜드 공식 발표·언론 보도에서 확인한 사실(이름·기간·장소·사은품)과 원문 링크. 사진·소개 글은 가져오지 않아요.
- 지도·위치 찾기·걷는 길(src/data/walk.json): © OpenStreetMap contributors, ODbL 1.0
